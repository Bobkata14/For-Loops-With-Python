🟢 Level 1 — Understanding the Basics
Exercise 1 — List of Names

You have:

names = ["Petar", "Ivan", "Maria", "Georgi", "Anna"]

Use `for` to print each name on a separate line.

Do not use `while`.

Exercise 2 — Favorite Games 🎮
games = ["Minecraft", "GTA V", "Hogwarts Legacy", "CS2", "WWE 2K16"]

Use `for` to print:

I like Minecraft
I like GTA V
...

💡 Use an f-string.

Exercise 3 — Numbers

numbers = [5, 10, 15, 20, 25]

Exercise 4 — Sum

You have:

numbers = [10, 20, 30, 40, 50]

Find the sum using `for`.

Total: 150

🟡 Level 2 — `for` + Conditions
Exercise 5 — Even Numbers

Exercise 6 — Positive and negative

You have:

numbers = [5, -3, 10, -8, 0, 15, -2]

Using `for` and `if`/`elif`/`else`, determine the status of each number:

5 → Positive
-3 → Negative
0 → Zero
Exercise 7 — Largest number

You have:

numbers = [12, 45, 7, 89, 23, 56]

Find the largest number using a `for` loop.

⚠️ Do not use `max()` for this exercise.

Here, you will need to devise the logic for keeping track of the current largest value.

🟠 Level 3 — `range()`

This introduces one of the most important aspects of the `for` loop. for i in range(5):
print(i)

The result is:

0
1
2
3
4

Important: range(5) goes up to 5 but does not include 5.

Exercise 9 — Even numbers

💡 Here, `range()` can take three values:

range(start, stop, step)

🔥 Final exercise — for the Challenge
Exercise 13 — Store Inventory

This is a small, real-world task.

You have:

products = ["Laptop", "Mouse", "Keyboard", "Monitor", "Headphones"]
prices = [1200, 50, 100, 500, 150]

Display them like this:

Laptop - 1200
Mouse - 50
Keyboard - 100
Monitor - 500
Headphones - 150

Then find:

the total value of all products;
the most expensive product;
how many products cost more than 100.
⭐ Bonus

Format the output like this:

1. Laptop - 1200
2. Mouse - 50
3. Keyboard - 100
...

Here you can use something you encountered earlier:

enumeration ()
